Gmail Agent CLI

A terminal tool that cleans up your Gmail: trashes the junk, stars what needs you, turns real appointments into calendar events, and archives what you have read. It runs entirely on your own computer. 

gmail --dry-run   # see what it would do
gmail             # do it
gmail --archive   # ...and clear read mail out of the Inbox too

What it does

  • Moves promotions, newsletters and spam to Gmail's Trash — you can always pull them back.
  • Stars mail that asks you something, names a deadline, or concerns money, security or travel.
  • Adds private calendar events from mail with a real date. No guests, no invitations, no duplicates.
  • Archives everything you have already read, when you ask it to with gmail --archive.
  • Leaves anything uncertain alone, and tells you about it.
  • gmail view also reads, searches, deletes, composes and replies — with AI drafts you edit first.

What it never does

  • Never permanently deletes mail.
  • Never sends an email without showing you the exact message and asking.
  • Never follows instructions written inside an email.
  • Never uploads attachments anywhere.
  • Never runs in the background or keeps your mail on a server.

Where your mail goes

Nowhere, unless you turn on AI. There is no service in the middle: the tool talks to Google with an OAuth app you register yourself, and — only if you choose it — to OpenAI with your own API key. Message bodies are never written to disk, and your credentials stay in your operating system's keychain.

Rules-only mode is a real mode: Gmail's own spam handling, your rules, and archiving read mail all work with nothing leaving your computer.

Install

Needs Node.js 22.19 or newer, and pnpm.

git clone https://github.com/wumich15/gmail-agent-cli.git
cd gmail-agent-cli
pnpm install --frozen-lockfile
pnpm build
pnpm link --global

gmail install

gmail install is a guided setup. It opens each Google Cloud page for you, collects the credentials, signs you in, asks how AI should work, and finishes with a preview that changes nothing. About ten minutes, once.

The full walkthrough, with every field named, is in docs/setup.md.

What it costs

The tool is free and MIT licensed, with no account and no telemetry. Rules-only mode costs nothing at all. With your own OpenAI key you pay OpenAI directly — one small classification call per message, which works out to cents per run.
