Gmail Agent

A terminal agent that cleans up your Gmail inbox and turns actionable mail into calendar events. It runs on your computer, when you run it.

Install

npm install --global gmail-agent-cli
gmail setup

Already installed? Run gmail setup. That opens a browser page, you approve Google access once, and you are done — there is no Cloud project to create, no credentials file to download, and no AI key to paste.

What it does

  • Moves spam, promotions, and confidently low-value automated mail to Trash — never a permanent delete.
  • Stars and marks important the mail you actually need to read.
  • Creates high-confidence calendar events from appointments, reservations, and deadlines.
  • Archives read mail when you ask it to, and prints exactly what it did.
  • Lets you read, reply to, and compose mail from the terminal, with a confirmation before anything sends.

Where your data goes

Your Google credentials stay in your operating system’s credential store and are never sent to [Publisher]. With the included AI turned on, bounded message text is sent through [Publisher] to an approved model service for classification and drafting, and for nothing else — see the Privacy Policy. You can also run it with your own AI key, or with no AI at all.
