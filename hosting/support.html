Where to get help, and what to try first.

Check the install

gmail doctor

This checks the Node runtime, the local database, the OS credential store, the Google sign-in, the Gmail API, the timezone, and whether AI is actually ready. It reads only; it never changes mail.

Common situations

  • “Run gmail setup to reconnect it.” The Google grant or the AI session expired or was revoked. gmail setup restores both.
  • “The included AI allowance is used up.” The run continues with rules only. Try again later, or switch to your own API key in gmail setup.
  • “Another gmail process is already running.” A gmail view session in another window holds the account lock while it loads. Let it finish, or close it.
  • Something was trashed that should not have been. Nothing is ever permanently deleted. Use gmail undo <run-id>, or restore it from Gmail’s Trash.
  • Wanting to see what a run would do. gmail --dry-run --limit 25 changes nothing.
